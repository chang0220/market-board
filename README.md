# 行情看板

美元/人民币汇率 + 比特币、以太坊走势的一页式看板。

**在线地址：** https://chang0220.github.io/market-board/

## 是什么

一个单文件的静态网页（`index.html`），没有后端、没有构建步骤、没有依赖。
所有数据由浏览器里的 JavaScript 直接向公开 API 请求。

| 数据 | 来源 | 更新频率 |
| --- | --- | --- |
| USD/CNY 汇率及历史 | [Frankfurter](https://frankfurter.dev)（欧洲央行参考汇率） | 工作日每天一次，**不是实时盘中价** |
| BTC、ETH 价格及走势 | [CoinGecko](https://www.coingecko.com) | 接近实时 |

## 功能

- 三张卡片：汇率、比特币、以太坊，各含现价、涨跌幅、区间高低、走势图
- 区间可切 7 / 30 / 90 天
- 走势图支持鼠标悬停 / 触摸查看具体某一点的时间和数值
- 币价自动按当前汇率折算成人民币
- USD ⇄ CNY 双向换算器
- 每 60 秒自动刷新；标签页切到后台时暂停，避免浪费 API 额度
- 数据存一份在 localStorage，重新打开先显示上次结果，不白屏
- 每张卡片附可展开的数据表
- 自动适配深色 / 浅色模式，手机端可加到主屏当 App 用

## 本地运行

不需要服务器，直接用浏览器打开 `index.html` 即可。

## 注意

- CoinGecko 免费接口有频率限制，短时间内大量刷新会被暂时拒绝。
- 数据仅供参考，不构成任何投资建议。
